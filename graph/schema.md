# Схема графа

## Типы узлов

| type | Префикс | Смысл |
|------|---------|--------|
| `wave` | `W` / `W1-…` | Волна / milestone |
| `feature` | `F-` | Кусок поведения со стыками |
| `rule` | `R-` | Разделяемое правило (≥2 фич) |
| `decision` | `D-` | Зафиксированный Options |
| `entity` | `E-` | Сущность данных/документа |
| `capability` | `C-` | Платформенная возможность |
| `integration` | `I-` | Внешний/внутренний контракт |

## Типы рёбер

| edge | Смысл |
|------|--------|
| `depends_on` | Без целевого узла фича невалидна |
| `blocks` | Состояние/правило блокирует действие |
| `shares_rule` | Фичи делят формулировку R-* |
| `shares_entity` | Общая сущность / поля |
| `enables` | Capability включает фичи |
| `conflicts_with` | Напряжение / нужно явное согласование |
| `complements` | Кажущийся конфликт, на деле согласовано |
| `refines` | Задача/подфича уточняет узел (обычно Tracker) |
| `tested_by` | Проверка / e2e |

## Статусы узлов (грубые)

`planned` | `specified` | `in_progress` | `testing` | `done` | `deferred` | `open` | `accepted`

Статусы поставки задач — в Трекере, не дублировать детально здесь.
