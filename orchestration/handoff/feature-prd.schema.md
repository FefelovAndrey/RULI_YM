# Handoff: Feature PRD — обязательные поля

См. шаблон `../../features/_template/PRD.md`.

Минимум, без которого Spec Auditor не пропускает:

1. problem / outcome  
2. scope in/out  
3. preconditions (`depends_on`)  
4. shared rules/entities (ID из графа)  
5. business rules (с источником)  
6. happy + fail flows  
7. systems touched  
8. acceptance criteria  
9. open questions (не прятать дыры)  
10. traceability к evidence / Tracker  

Связь с графом: id фичи = id узла `F-*` в `graph/graph.yaml`.
