# secrets/

Локальные креды. **Не коммитить** значения (см. `.gitignore`).

## Что класть сюда

| Файл (пример) | Назначение |
|---------------|------------|
| `local.env` | Переменные из `.env.example` |
| `ym-api.env` | Токены Partner API ЯМ (когда появятся) |

## Что не дублировать

Yandex Tracker org/token — обычно уже в `~/.cursor/secrets/yandex-tracker.env`.  
Дублировать только если нужны отдельные ключи именно для этого проекта.

## Для агентов

- Не читать и не цитировать значения секретов в ответах пользователю без необходимости.
- Не вставлять токены в markdown репозитория.
- Имена переменных и назначение — только здесь и в `.env.example`.
