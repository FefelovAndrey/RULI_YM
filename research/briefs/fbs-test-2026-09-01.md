## Доработки (чеклист)

Приоритет: **P0** — ломает прод-путь; **P1** — обход есть, но оператор спотыкается; **P2** — долг/гигиена.

### P0 — приёмка и ярлык

- [ ] **Писать** `shop_ym_order_state` **при** `/order/accept`**.** Сейчас `shopYmApi::createOrder` заказ создаёт, строку состояния — нет. Дальше `updateByField` бьёт в пустоту. Из-за этого `shopClabelsMarket::getOrderCheckInfo` держит `is_label = false`, и кнопка «Получить наклейку» на Сборке не появляется, пока нет Shop `shipped` **и** (`PROCESSING_READY_TO_SHIP` или кэш PDF). Обход сегодня: PDF с карточки YM / `marketPrintLabel` в консоли.
- [ ] **Сверить гейт ярлыка с реальным статусом Маркета**, не только с локальным `ym_order_state`. После ручного PUT READY_TO_SHIP кнопка всё равно могла не открыться.



### P1 — операторский контур сборки

- [ ] **Вкладка «Подбор»** в `BackendNav.html` закомментирована — либо вернуть, либо явно документировать путь: список заказов → `in_stock` → «На упаковку» → Сборка clabels.
- [ ] **Действие workflow** `ship` **подписано «Отправлен»** и доступно повторно из `shipped`. Не жать второй раз. Подпись/ACL: одноразовость или скрытие после первого успеха.
- [ ] **1С-гейт в CheckResult** пропускается/глотается, если нет `id_1c` или заказ уже `shipped`. Для теста ок, для боя — явный статус «1С не привязана», а не тихий skip.
- [ ] **Печать:** clabels «Получить наклейку» → QZ, не скачивание PDF. Карточка YM → скачивание. Нужен один понятный путь (или оба, но с подписью). Повторная печать блокируется, если уже есть `master_barcode`.
- [ ] **Камера /** `is_testing`**:** на бою не оставлять тестовый обход авторизации склада.



### P1 — first-mile (rulimpsupplies)

- [ ] **Дефолт даты = сегодня**, дефолтные статусы **без** `OUTBOUND_CREATED` — пустой список при живых актах в статусе «создана». Либо расширить дефолт, либо подсказка в UI.
- [ ] **Fake-заказы не попадают в реальные отгрузки** — ожидаемо. Для боя: прогон на живом FBS `fake: false`.
- [ ] Не подтверждать чужие акты со стенда.



### P2 — клиент Partner API

- [ ] `shopYmApi`: старый OAuth + суффикс `.json` на URL. Сегодня HTTP 200, но это долг (Api-Key / без `.json`).
- [ ] **Hardcoded OAuth в** `rulimpsuppliesYmApi::getWarehouses` — вынести в настройки профиля, ротировать токен. Значение в git/чаты не копировать.



### Следующий тест (не этот заказ)

- [ ] Живой FBS, `fake: false`, авто-приёмка без Postman.
- [ ] Повторить сборку и убедиться, что после фикса `ym_order_state` кнопка ярлыка на Сборке открывается сама.
- [ ] First-mile: своя отгрузка, слот, акт — без чужих документов.
